## 实现与真实失败记录

| 项目 | 实测缺口 | 修改与验证 |
|---|---|---|
| 首错位置 | 堆分配失败及 `length_error`、未知宿主异常没有保存当前指令范围 | VM 在清理帧前补齐首错缺失位置；保留原分类、OS 代码及已有位置 |
| 用户调用链 | 函数记录采用函数内失败位置，规范 demo 的 inner、outer 调用点不符 | 使用已提交帧的 `caller_call_ip`，demo 首行 2:14，inner 5:12、outer 7:7；预检失败的目标不入链 |
| 诊断文本分配 | 第一次故障注入只覆盖链保存，无法验证后续排版失败 | 第一次命中覆盖链保存，第二次覆盖拥有文本的 Diagnostic 构造；失败后一次固定报告，退出 1 保留 |
| 帮助与版本输出 | 首轮完整 CI 检出只读 stdout 导致退出 1 | 平台输出传播 IoFailure；MYB 内置记录 Runtime，命令边界记录 Internal，真实 CLI 复验退出 3 |
| 深层工作区 | 原注入只支持首个命中，无法检查已有部分副本或显示路径时的失败 | 增加指定命中次数，复制第 2/4/7/8 次及显示第 7/8/10 次命中后检查对象、原图、旧输出和根清理 |

`Diagnostic` 拥有完整排版文本，可在原源码、名称存储和会话销毁后报告。用户控制字符、NUL 和非法 UTF-8 字节被转义。无位置的入口失败不生成虚构行列。`report_failure` 写出失败后停止；最小 Windows 报告使用固定 ASCII/UTF-16 数组直接写句柄，保留原退出类别。

跨模块用例主动触发 HeapObject、HeapRegistry、Payload、MarkWorklist、ProgramConstants、NativeWorkspace、VmValues、VmStates、VmFrames、IterationRecords、FlexAllocation、DiagnosticSnapshot 和 OS 读写关闭故障。外部 `RootedValue` 在 VM 清理后继续保活被遍历数组，随后检查活动计数为零；标记失败检查原对象仍存活，清理后可再次正常回收。
