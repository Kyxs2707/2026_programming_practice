## 2. 长行输入

[long-line.txt](../../tests/console/manual-input/long-line.txt) 含 **4095 个小写 `a`，末尾接一个 `😀`**。文件为无 BOM 的 UTF-8，末尾没有换行；共 4096 个 Unicode 码点、4097 个 UTF-16 单元。

把下面整块命令一起复制执行。`Set-Clipboard` 会将剪贴板替换为该长行，随后启动交互程序：

```powershell
& {
    $ErrorActionPreference = 'Stop'
    Set-Location -LiteralPath 'E:\ProgramData\Project\202609_BUPT_programming_practice'
    chcp 936
    Set-Clipboard -Value (Get-Content -LiteralPath ./tests/console/manual-input/long-line.txt -Raw -Encoding utf8)
    Write-Host 'CASE: 通用终端检查 936'
    ./build/release/myb.exe ./tests/console/interactive.myb
    $mybInteractiveExit = $LASTEXITCODE
    Write-Output "INTERACTIVE exit: $mybInteractiveExit"
}
```

看到 `WAITING FOR INPUT` 后，先粘贴剪贴板中的长行，再按 Enter。此时先完成长行检查，再复制本文的其他文字，避免覆盖剪贴板。

预期：程序显示一行 `RECEIVED ["aaa…😀"]`，其中省略号代表文件中的其余 `a`；末尾 emoji 完整，随后再次显示 `WAITING FOR INPUT`。若终端粘贴时拒绝、截断或发出提示音，记录实际现象和末尾收到的内容，该组合保留待查。

本节通用命令为 936；其他组合使用上方对应的独立检查文件。

## 3. 普通输入、空行和控制键

在刚才仍显示 `WAITING FOR INPUT` 的程序中，依次完成下表。每次只操作一行。

| 顺序 | 输入或按键 | 预期程序输出 |
|---|---|---|
| 1 | 输入 `plain-123`，按 Enter | `RECEIVED ["plain-123"]`；字符串中没有残留 `\r` 或 `\n` |
| 2 | 输入或粘贴 `你好😀`，按 Enter | `RECEIVED ["你好😀"]`；中文和 emoji 显示正常 |
| 3 | 直接按 Enter | `RECEIVED [""]` |
| 4 | 输入 `ab`，按一次 Ctrl+Z，再输入 `cd`，最后按 Enter | `RECEIVED ["ab\u{1a}cd"]`；程序继续等待 |
| 5 | 在新行只按 Ctrl+Z，再按 Enter | 依次显示下方三行，并结束程序 |

```text
EOF: read_line() returned null.
REPEATED EOF: null
DONE: leaving the interactive check.
```

表中的 Ctrl+Z 表示实际按键组合，不能输入字面文字 `Ctrl+Z` 或 `^Z`。终端可能将该键回显成 `^Z`；判断依据为 `RECEIVED` 中的转义内容和 EOF 提示。

程序退出后，启动块会自动打印 `INTERACTIVE exit: 0`。需要再次输入时重新执行完整启动块。Ctrl+C 用于中断程序，正常 EOF 使用第 5 步。

## 4. 长输出显示

[output.txt](../../tests/console/manual-input/output.txt) 含 8901 个 UTF-16 单元：4095 个 `a`、一个 `😀`、1200 组 `中文😀`，末尾为 ` END`。它沿用自动控制台检查的数据。

在同一个终端执行下面整块命令。它会自行定位项目目录并设置代码页，可独立执行：

```powershell
& {
    $ErrorActionPreference = 'Stop'
    Set-Location -LiteralPath 'E:\ProgramData\Project\202609_BUPT_programming_practice'
    chcp 936
    Write-Host 'OUTPUT CASE: 通用终端检查 936'
    $mybManualExe = (Resolve-Path ./build/release/myb.exe).Path
    $mybManualOutputScript = (Resolve-Path ./tests/console/write_unicode.myb).Path
    Push-Location ./tests/console/manual-input
    try {
        & $mybManualExe $mybManualOutputScript
        $mybManualOutputExit = $LASTEXITCODE
    } finally {
        Pop-Location
    }
    Write-Output "MYB exit: $mybManualOutputExit"
}
```

程序会跨多行显示长文本。检查最前面的 `a` 区域之后首个 emoji、后续连续中文/emoji、末尾 ` END` 是否完整；终端自动折行属于正常显示。预期最后显示 `MYB exit: 0`。记录方框、替代字符、缺字或边界断裂等实际显示问题。

此命令在输入目录中读取 `output.txt`；完整路径变量让它仍能运行仓库的 Release 程序和既有 MYB 脚本。
